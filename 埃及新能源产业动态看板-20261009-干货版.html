ACTION 01

如果你卖组件 / 逆变器

优先锁定 Scatec、AMEA、ACWA 等开发商项目供应链及当地 EPC；同时让埃及进口商先确认 GOEIC 产品归类、生产商注册 / 认可检验证明与 ACI。

第一步：拿 HS Code + 产品规格书给当地清关 / 合规伙伴做预审。
ACTION 02

如果你卖储能

不要把“埃及储能市场”理解成户储市场。当前最有确定性的需求来自大型 PV + BESS 及独立电网储能项目。

第一步：围绕 Abydos / Obelisk 等项目，找开发商、EPC、融资方，而不是先找零售商。
ACTION 03

如果你做风电 / 电气设备

重点区域集中在 Gulf of Suez / Ras Ghareb。除了风机本体，输电、集电、变电、并网设备和 EPC 同样值得切入。

第一步：从项目业主 → EPC → 并网工程倒推供应商名录。

对合规产品优化检验流程；注册生产商或具认可检验 / 审核证明的货物可获得便利，同时保留持续合规核验。

持续

ACI / ACID

NAFEZA 官方说明：ACI 要求进口货物在装运前提交货物数据 / 文件，以进行风险管理；常见文件包括商业发票、装箱单、提单副本、原产地证，视货物可能追加检验、分析、保险、MSDS 等文件。

企业动作：不要等货到港再补合规。应在报价 / 签约阶段就让埃及进口商和清关代理确认 ACID、GOEIC、产品证书及项目文件链。

12 出海避坑清单 把最容易浪费销售资源的动作直接删掉

× 不要先做泛渠道招商

当前大型项目集中度高。先找到项目和 EPC，再判断当地渠道价值。

× 不要只拿 IEC 证书就报价

GOEIC 特殊进口条件、生产商注册 / 认可检验证明、ACI / ACID 及项目技术规范是不同环节。

× 不要把 HS 进口额当市场规模

854140、850780 等只是贸易代理指标；项目市场容量应结合招标、PPA、项目设备包判断。

13 甲子申｜市场判断 从“卖设备”到“进入项目体系”

01 · 光伏

埃及的主战场仍是大型集中式项目。中国企业若只做“组件价格竞争”，容易陷入同质化；更有价值的是进入开发商、EPC、EETC 项目采购体系。

02 · 储能

这是三个赛道里最值得跟踪的增量。Abydos II、Obelisk 等项目证明 BESS 正在进入电网级项目；同时政策开始强调本地制造与电网稳定。

03 · 风电

大型化和区域集中化非常明显。Gulf of Suez / Ras Ghareb 项目密集，未来竞争点会逐步从单机设备扩展到 EPC、并网与电网配套。

一句话：埃及不是简单的“低价出口市场”。真正值得研究的是：谁拿项目 → 谁做 EPC → 谁采购设备 → 谁负责并网 → 谁是购电方 → 中国企业处在哪一层。
