甲子申网站三项功能更新包｜部署说明

本包对应三个需求：
1. 后台支持 HTML 上传；新增看板并发布，或选择已有看板替换内容（旧文件路径保留，不会新增重复看板记录）。
2. 修复会员状态页自动跳回：只有有效会员才会在带 return 参数时自动返回看板；未开通用户停留在会员状态页。
3. 去掉“会员专享”访问模式，采用“完全公开 / 半公开”两种模式。半公开看板：游客预览 → 注册/登录 → 管理员开通会员 → 查看完整 HTML。

文件说明
- admin.html：后台（含国家/产业/专题、看板上传/替换、会员管理）
- index.html：首页文案更新
- viewer.html：半公开预览与会员完整访问流程
- member.html：会员状态页跳转修复
- jiazishen_semi_public_membership_update.sql：数据库与存储桶升级脚本
- get-private-dashboard-index.ts：Supabase Edge Function 源码

部署顺序（不要跳步）
1. 先备份 GitHub 仓库中的 admin.html、viewer.html、member.html、index.html。
2. 在 Supabase SQL Editor 的甲子申项目执行 jiazishen_semi_public_membership_update.sql。若出现错误，先停下并把完整错误发给开发者，不要重复运行不同 SQL。
3. Supabase → Edge Functions → get-private-dashboard：用本包 get-private-dashboard-index.ts 的完整内容替换函数代码并部署。确认函数仍使用平台环境变量 SUPABASE_URL、SUPABASE_ANON_KEY、SUPABASE_SERVICE_ROLE_KEY；不要把 Service Role Key 放到网页文件里。
4. 在 GitHub 仓库根目录上传并覆盖 admin.html、index.html、viewer.html；新增或覆盖 member.html。
5. 等 GitHub Pages 发布后，先用管理员登录后台，再进行测试。

后台上传看板
- 新增半公开看板：选择“新增看板并发布”；填写名称、国家、产业、简介和标签；访问方式保持“半公开”；点击“上传完整看板 HTML”上传完整版本（私有）；再点击“上传游客预览版 HTML”上传只含公开信息的预览版；最后点击“上传并发布看板”。
- 替换已有看板：选择“替换已有看板内容”；从下拉框选中要替换的看板；上传新版完整 HTML 和新版预览 HTML；点击“上传并替换原看板”。会更新原有 demos 记录，不会新建重复记录；旧 HTML 文件仍留在 Storage 中作为备份。
- 完全公开看板：访问方式选“完全公开”，上传完整 HTML，或填写公开网址，然后发布。

重要注意
- 半公开模式必须上传两份文件：完整 HTML（私有桶）和游客预览 HTML（公开桶）。这是为了避免游客绕过遮罩直接打开完整文件；预览版只能包含允许游客查看的内容。不要把完整版本当作预览版，也不要把完整 HTML 放到 GitHub Pages 或公开桶。
- 旧版本中如果存在“会员专享”看板，升级 SQL 会将其访问模式转换为“半公开”；这些旧看板仍需在后台编辑并上传独立的游客预览版 HTML，否则页面会提示缺少预览版。
- 推荐自包含 HTML；如果 HTML 依赖同目录图片、JSON、CSS 或数据文件，本包的单文件上传不会自动打包这些资源。
- 会员开通仍是人工方式：用户注册/登录后提供注册邮箱，管理员在“会员管理”中核实付款后开通有效期。
- 仅完成文件上传和 SQL 代码检查，尚未连接你的 Supabase 实际环境进行端到端测试；部署后请按下面测试清单逐项验证。

测试清单
1. 管理员登录后台，国家、产业、看板、专题列表均正常显示。
2. 新增测试半公开看板：上传完整 HTML + 预览 HTML，发布后首页出现一条新记录。
3. 选择该看板执行“替换已有看板内容”，上传新文件后首页仍只有一条记录，打开后显示新版内容。
4. 未登录游客打开半公开看板，能看到预览并看到登录/注册入口。
5. 登录但未开通会员的账号，仍只能看预览；member.html 应停留显示未开通状态，不应自动跳回。
6. 管理员开通该账号后，刷新会员状态页，应返回原看板；完整 HTML 只在服务端验证会员后加载。
7. 完全公开看板仍能直接打开。
